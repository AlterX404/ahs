OPTIMIZED EXPERIENCE

Jujutsu Infinite was added with a V1.0.0 feature set on February 15, 2025 and received a loading and crash fix two days later.

Dated release history

Jujutsu Infinite added

February 15, 2025

V1.0.0

  • New UI
  • Main: Infinite Spins, Insta Kill, TP to Mobs, Auto Boss, Freeze Enemies
  • Auto Daily Quest with daily quest missions and mobs
  • Misc: Item ESP, Auto Collect, Auto Promote, Auto Collect Chest, gamepass-related utilities, Skill Giver, Weapon Giver
  • Move Redeemer
  • Discord Webhook

Loading and crash fix

February 17, 2025
  • Fixed Jujutsu Infinite loading and crashing issues

Before reporting a problem

Check whether the issue started after a game update and whether Alter Hub itself still opens. Include the game name, the feature or tab involved, the visible error text, and the date you tested. Do not publish private keys or account credentials.

For access problems, use the Key System guide. For general errors, use Troubleshooting or the Support page.
