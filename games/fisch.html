Fisch support notes

Current Alter Hub support information for Fisch, including the public status label, compatibility checks, and what to include in a useful problem report.

Alter Hub documentationUpdated August 20, 2026

Current public status

PERFORMANCE OPTIMIZED

Fisch is currently presented with a “Performance Optimized” status on the Alter Hub homepage. Rather than inventing undocumented performance numbers, this page explains what users should verify when the experience or Alter Hub changes.

No invented feature list. The current source site does not publish a verified, game-specific feature catalog for Fisch. This page therefore documents support status and troubleshooting without pretending otherwise.

Do not treat a label as a benchmark

The public status label is descriptive, not a published FPS or latency guarantee. Actual performance depends on the supported environment, the experience itself, and current compatibility.

For general access or session errors, use the Troubleshooting guide. For temporary key behavior, use the Key System guide.

If Fisch updates

Check whether the Alter Hub interface still loads normally and whether the issue is isolated to Fisch. If access works but behavior changes only in this experience, report it as a game compatibility issue.

For general access or session errors, use the Troubleshooting guide. For temporary key behavior, use the Key System guide.

Make performance reports measurable

Describe what became slower or stopped responding, when it began, and whether the change followed a game update. Avoid vague claims such as “laggy” without identifying the screen or action affected.

For general access or session errors, use the Troubleshooting guide. For temporary key behavior, use the Key System guide.

Report a compatibility change

  1. Name the game and the public status you saw.
  2. State whether the problem is website access, key verification, loader startup, or behavior inside the experience.
  3. Copy the exact error text without exposing private keys.
  4. Say whether the game updated immediately before the issue.
  5. Provide a screenshot only if it does not reveal private account or billing data.

Use the Support page for the current contact channels.
