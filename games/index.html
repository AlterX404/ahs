How these pages are maintained

Game pages use dated Alter Hub release notes supplied by the project owner. They keep historical feature names and release dates tied to the update in which they were announced. A historical feature should not be assumed current unless a newer support note confirms it.

This approach keeps the directory useful without creating thin pages or invented compatibility claims.
