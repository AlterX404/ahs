How to read a support status

A status label describes the way Alter Hub currently presents support on the public website. It is not a permanent guarantee that every function will survive every game update. When an experience changes, compatibility should be retested and the status or support notes should be updated if needed.

For a problem that began after an update, use the Troubleshooting guide and include the game name, the date the behavior changed, and the exact failure point.
