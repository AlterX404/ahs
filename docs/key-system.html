What the key system does

The free access path gives Alter Hub a temporary way to verify an active browser session before a key is accepted in the client. The in-game interface creates or retrieves the session link, the browser completes the verification flow, and the final key is then checked back in Alter Hub.

Verification stages3 checkpoints
Key-session window15 minutes
Generated key validity12 hours

Same device matters. The current flow associates access with the device/session that created it. Avoid copying an active key session to another device or sharing the generated key.

Complete walkthrough

Follow the steps in order. Opening multiple competing verification sessions or reusing an old callback can cause the session to be rejected.

01

Open the Key System tab

In Alter Hub, open the Key System screen shown in the interactive preview above.

02

Press Copy Key Link

The client creates or retrieves your current key-system URL and copies it so you can open the browser verification page.

03

Open the copied link

Open the official api.alterhub.online session URL. Do not use a key link copied from another person.

04

Pass the human check

Before checkpoint one, complete the Cloudflare Turnstile human verification. If the challenge expires, complete a fresh one.

05

Complete checkpoint 1

Choose an available provider, such as Linkvertise or LootLabs, finish the provider flow, and return to Alter Hub's session page.

06

Finish checkpoints 2 and 3

Continue the verified flow until all three checkpoints are complete. The later checkpoints do not require another Turnstile challenge in the same session.

07

Copy the generated key

After checkpoint three, the result page shows the temporary Alter Hub key and its remaining validity time.

08

Paste and Verify Key

Return to the in-game Key System, paste the key into Enter Key, then press Verify Key. Keep the key private.

Why the browser checks exist

The browser page is not just a visual timer. The first checkpoint requires a server-verified Cloudflare Turnstile token, and checkpoint completion is confirmed by the selected provider before the session progresses. Direct session advancement is disabled in the current Worker.

A successful challenge only proves the current browser passed the human check for that request. It does not make a copied or expired session valid, and it does not turn the interactive demo above into a real key generator.

Never send support your full generated key. If something fails, send the error message, the checkpoint number, and a screenshot with the key hidden.

Common key-system problems

Turnstile does not complete

Reload the current checkpoint page, allow JavaScript and cookies, then complete a fresh challenge. A stale Turnstile token cannot be reused.

403 during checkpoint start

Checkpoint one was requested without a valid human-verification token, or the token expired. Complete Turnstile again and retry from the current page.

Session expired

The verification session is temporary. Return to the in-game Key System and use Copy Key Link again to create or retrieve a current session.

Checkpoint already used

Do not retry the same provider callback. Return to the current Alter Hub session page and continue from the checkpoint it shows.

Key rejected in game

Confirm that the key was copied completely, has not expired, and is being redeemed on the same device used for the verification flow.

Key expired

Generate a new session and complete the current access flow again. Old result pages are not permanent credentials.

Key-system FAQ

Do I need to solve Turnstile three times?

No. In the current flow, the human verification is required before the first checkpoint. Checkpoints two and three continue under the same valid session.

Can I share a key with somebody else?

No. Treat a generated key like a temporary credential. The current access flow is designed around the device/session that created it.

Why does the key page expire?

The temporary session prevents old browser links from remaining useful indefinitely. A completed key has a separate validity period.

Is the interactive model above connected to my account?

No. It is a front-end demonstration of the current Alter Hub interface. It does not create a live session, complete providers, or verify a real key.

Ready to use the real key system?

Open Alter Hub, copy your current key link from the in-game interface, and follow the verification page it generates.
