FAQ

Alter Hub FAQ

Answers to common questions about access paths, supported experiences, key sessions, purchases, and where to get help.

Alter Hub documentationUpdated August 20, 2026

Access and plans

Is the free access flow the same as Keyless?

No. The site describes Keyless as a paid access option that skips the free key-system checkpoints while Keyless access remains active. Always check the Keyless plan page for the current terms.

Are Premium and Premium Plus the same?

No. They are separate public tiers with different descriptions and prices. Use the individual plan pages rather than a screenshot or old message when comparing them.

Can a temporary key link be reused forever?

No. Key sessions and generated keys can expire. A session or result page is a functional screen, not a permanent content page.

Games and compatibility

Where is the current supported-game list?

Use the Supported Games directory. The homepage also shows the current public list, but the directory is where detailed support notes are being maintained.

Why can support change after an update?

Each Roblox experience can update independently. When an experience changes, compatibility may need to be tested again before the public status is treated as current.

Why do some game pages have more detail than others?

We publish detailed pages when we have enough verified information to make them useful. A short placeholder copied across fifteen games would not help users, so the remaining titles stay in the directory until stronger notes are available.

Billing and support

Where should I ask a purchase question?

Use the official support email or Discord support channel. Do not post PayPal transaction identifiers, billing email addresses, or other personal information in a public channel.

Where are refunds and subscription terms explained?

The Terms of Service describe purchases, subscriptions, digital access, refunds, and other account rules. The plan page should also state whether a selection renews automatically.

Website and documentation

Why are there no ads on key or verification pages?

Those screens exist to complete an access action. Alter Hub keeps monetized publisher content separate from temporary behavioral and verification screens so the user can distinguish documentation from access mechanics.

How can I report an outdated guide?

Send the page URL, the heading that is wrong, what you saw instead, and a screenshot if it helps. Documentation corrections are tracked separately from billing issues.
