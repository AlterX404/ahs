GETTING STARTED

Start with Alter Hub

Use the official public site as your source of truth, check compatibility before opening a supported experience, and keep temporary access links private.

Alter Hub documentationUpdated August 20, 2026

Start with the public site, not a copied link

The safest starting point is the main Alter Hub website. It contains the current pricing pages, supported-game directory, documentation, legal pages, and links to the official community channels.

Links to temporary key or result pages can expire and should not be bookmarked as permanent entry points. The public site is also where changes to supported experiences and access options can be documented without relying on an old message or copied URL.

Choose the access path that matches what you need

Alter Hub currently presents a free access path and paid access tiers. The public pricing section distinguishes Keyless, Premium, and Premium Plus. The exact benefits shown on the pricing pages should be treated as the current source of truth for those plans.

  • Free access: may use the public access page and a temporary key/verification flow.
  • Keyless: is described on the site as skipping free key-system checkpoints while access is active.
  • Premium: includes Keyless plus the Premium benefits listed on the Premium page.
  • Premium Plus: is the highest public tier and should be checked against its own pricing page before purchase.

Do not rely on screenshots of old prices or plan descriptions. Use the live pricing page because pricing and included benefits can change.

Before opening a supported experience

  1. Check the Supported Games directory. A game update can temporarily affect compatibility even when a title is generally supported.
  2. Use the current Alter Hub loader or access link from the official site rather than an old copy saved elsewhere.
  3. If you are sent to a key session, keep that tab open while you complete the provider checkpoint. Sessions are temporary by design.
  4. Keep generated keys private. They are credentials for your access flow, not text to post in public channels.
  5. If something fails, note the game, the step you reached, the visible error, and whether the problem began after a game update.

What a useful support report looks like

“It does not work” is difficult to diagnose. A useful report tells support what changed and where. Include the supported game, the page or screen you were on, the exact error text, whether you were using a free key or paid access, and the last step that worked normally.

For billing or plan questions, do not post transaction identifiers or personal information publicly. Use the support email or the official support channel listed on the Contact page.
