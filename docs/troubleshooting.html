Troubleshoot Alter Hub

Find the first point of failure, separate session issues from game compatibility changes, and send support reports that can actually be reproduced.

Alter Hub documentationUpdated August 20, 2026

Start with the failure point

Troubleshooting is faster when you identify the first thing that stopped working. Separate website problems, key-session problems, game compatibility changes, and billing questions instead of treating all of them as the same issue.

SymptomFirst check
The website does not load correctlyTry the main domain directly and confirm that static assets are loading.
A key page says the session expiredStart a fresh session from the current official access path.
A provider completed but progress did not advanceReturn to the same session tab and capture the exact message shown.
Alter Hub stopped working after a game updateCheck the game support page and the changelog before reinstalling anything.
A paid plan is not activatingUse Support and keep billing details private; do not post transaction data publicly.

Key and session problems

Invalid or expired link

Temporary key URLs are not permanent bookmarks. If the page reports that the session no longer exists or has expired, return to the official access path and create a new session.

Provider callback did not complete

Keep the original Alter Hub session tab open while using the provider. When you report the problem, include the provider name, the checkpoint number, and the exact message shown after returning.

Generated key is rejected

Confirm that the key was copied completely and that it has not expired. Do not publish the key while asking for help.

Game compatibility changed

Roblox experiences can update independently of Alter Hub. A significant game update can change behavior that previously worked. If the issue started immediately after a game update, record that timing in your report and check the public game directory before assuming your local setup is the cause.

The support pages intentionally avoid promising that every feature will work forever. Compatibility information should be updated as the platform is tested.

Send a report that can be reproduced

  1. Name the supported game and the access tier you were using.
  2. State the page or screen where the failure happened.
  3. Copy the exact error message, but remove keys, transaction IDs, or personal information.
  4. Explain the last action that worked before the failure.
  5. Say whether the issue began after a game, website, or Alter Hub update.
  6. Add a screenshot if it reveals the interface state without exposing a private key.

Send technical or account-specific reports through the channels on the Contact page.
