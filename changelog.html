Public release notes

This changelog starts with changes that can be verified from the current site rebuild. Older product history is not backfilled with invented version numbers.

Public site content rebuild

August 20, 2026

Added

  • Documentation hub with Getting Started, Installation, Key System, Troubleshooting, and FAQ guides.
  • Supported-game directory and five detailed public support-note pages.
  • About and Contact pages with clearer support routing.
  • robots.txt, sitemap.xml, canonical links, and indexing rules for functional access pages.

Changed

  • Homepage navigation now gives Games, Documentation, Updates, About, and Support more prominence.
  • Public content is separated from key, result, and other temporary behavioral screens.

Advertising and indexing

  • Removed third-party display and pop-under advertising from the public get-script task page.
  • Removed display-ad and anti-adblock gating from the Cloudflare key/result Worker pages in the accompanying Worker build.
  • Marked temporary access/key/result screens for noindex behavior rather than treating them as publisher content.

Release-note standard

Future entries should describe actual changes that shipped. If a compatibility update affects only one supported experience, name that experience and the behavior that changed. If a date or version cannot be verified, do not invent one for the sake of making the changelog look older.
